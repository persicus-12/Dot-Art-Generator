A Python desktop application that converts images into text-based dot art using Unicode Braille characters.

## Features

- Image-to-Braille art conversion
- Simple character-based art mode
- Atkinson dithering
- Floyd-Steinberg dithering
- Ordered dithering
- Adjustable output width
- Adjustable threshold
- Black-on-white mode
- Chat mode for cleaner text output
- Telegram-friendly copy option
- Copy generated art to clipboard
- Save generated art as a TXT file
- Supports JPG, JPEG, PNG, BMP, WEBP and GIF images

## Requirements

- Python 3.10 or newer
- Pillow
- Tkinter
